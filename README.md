# MP3 Tag Reader and Editor

A C-based application for viewing and editing ID3v2 metadata tags in MP3 files.

## Features

* View MP3 metadata tags
* Edit Title, Artist, Album, Year, Genre, and Comment fields
* Command-line interface
* Supports ID3v2 tag format
* File handling and binary file processing in C

## Supported Tags

* Title (TIT2)
* Artist (TPE1)
* Album (TALB)
* Year (TYER)
* Genre (TCON)
* Comment (COMM)

## Technologies Used

* C Programming
* File Handling
* Binary File Processing
